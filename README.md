## 资料记录约定

- 分别标注现场观察、店方自述、公开资料与小组估算。
- 未知、拒答和不适用不填为0；估算注明依据、区间、单位和对应时期。
- 当前上传文件为空白模板，不包含真实门店经营数据。
- 本仓库公开；后续公开真实资料前，移除私人联系方式、原始录音和未获公开授权的经营信息。
