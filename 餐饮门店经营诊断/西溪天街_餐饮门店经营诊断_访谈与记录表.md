# 西溪天街餐饮门店经营诊断：访谈与记录表

## 01 课程需求与现场使用说明

餐饮门店经营诊断｜杭州西溪天街｜3人小组｜计划2026年9月24日17:00到场。本文为调研工具，所有门店经营数据均待现场填写。

| 课程要求 | 需要形成的证据与结论 |
| --- | --- |
| 实地走访2—3家 | 完成至少2家有效走访，第三家备选；记录时间、位置、受访者身份。补充学校与商圈距离或交通时间，说明选址理由。 |
| ①分析各门店经营现状 | 每店形成定位与客群、价格、订单/人数、渠道、主要成本、经营变化和盈亏判断。 |
| ②亏损原因与改善方案 | 用观察、访谈与估算支持原因；提出对应措施、执行安排、成本代价和验证指标。 |
| ②盈利门店成功核心因素 | 解释优势如何带来收入、复购、效率或成本改善，并提供证据和其他可能解释。 |
| 允许合理推算，但须注明 | 逐项记录估算依据、区间及口径，区分经营结余与完整净利润。无法判断时明确说明。 |

选样：优先同品类、相近价格带、位置接近的两店。不可按现场热闹程度预先认定盈亏。只调查盈利店时照实分析，不虚构亏损店。

| 时间 | 三人行动 |
| --- | --- |
| 17:00—17:25 | 扫店、选2家＋备选、联系负责人。1号主访；2号记录；3号观察。 |
| 17:25—18:15 | 依次访谈A/B店，各约25分钟，含20分钟观察；采访本身约5—8分钟。 |
| 18:15—18:35 | 1、3号分别在A/B同步观察20分钟，2号补访。记录位置与可见范围。 |
| 18:35—19:15 | 顾客短访、必要补问、离场前核对。第三家仅在时间足够时加入。 |

打印：第2—3页为共用提纲；第4—7页为单店空白记录包，每店打印一套（两店共8页）；第8—9页为事后分析。电子填写时也请每店复制第4—7页。

来源编码：O=现场观察；I=访谈（写身份）；P=公开资料（写页面/菜单与日期）；E=估算（写依据与区间）。不知道写“未知”，拒答写“未提供”，不适用写“不适用”；均不等于0。

## 02 店方访谈题目表｜核心题

开场：您好，我们是【学校】学生，正在完成餐饮经营诊断课程作业。能否请负责人交流5—8分钟？金额可说范围或跳过，报告可匿名。现在忙的话，我们等您方便时再来。

以文字记录为主。录音、拍摄以及可否具名分别征询，不以赠礼换取回答。只剩3分钟时优先Q2、Q3、Q5、Q6。

| 编号／用途 | 直接提问 | 核对与记录位置 |
| --- | --- | --- |
| Q1 客群定位 | 主要顾客是哪类人？他们通常为什么选择这里？工作日和周末有何区别？ | 记录自述依据，勿直接将“学生多”写成统计事实。→第4页 |
| Q2 收入单价 | 堂食顾客优惠后实际人均约多少？外卖平均每单销售额约多少？ | 元/人或元/单；外卖扣费前销售额还是结算额。→第4页 |
| Q3 业务量 | 普通工作日和周末，一天堂食约接待多少人、外卖多少单？不方便可说区间。 | 人数≠订单；全天≠晚高峰；询问典型时期。→第4页 |
| Q4 成本压力 | 食材、人工、房租等哪项压力最大？方便说月度范围或占比吗？ | 依次询问，不一次追问所有敏感金额。→第5页 |
| Q5 经营状态 | 最近总体有盈余、基本持平，还是有经营压力？是最近一个月还是较长期情况？ | “压力大”不自动等于亏损；仅记录受访者能确认的状态。→第4页 |
| Q6 核心原因 | 您认为最影响经营结果的因素是什么？有没有近期具体例子？ | 区分现象与原因，追问发生时间和证据。→第7页 |
| Q7 既有措施 | 为此尝试过什么办法？效果怎样，有没有付出额外成本？ | 问前后变化和同期其他因素，不直接归因。→第7页 |
| Q8 成功优势 | 如果经营有盈余，最重要的优势是什么？顾客或经营表现如何体现？ | 适用于盈利或表现稳定的店；其他店可跳过。→第7页 |

结束核对：刚才的【数字】是【时期】的【人数/订单数】，包含【堂食/外卖】吗？我们会分别注明您提供的信息与小组估算。谢谢您的帮助。

## 03 追问题目与顾客短访

| 选问题 | 中性问法及用途 |
| --- | --- |
| Q9 时段与渠道 | 午晚餐、平峰各有什么特点？堂食与外卖哪个占比高、贡献较好？占比是收入还是订单？ |
| Q10 食材损耗 | 每100元销售额，食材大约占多少？是否包含报损、员工餐？损耗是另算还是已包含？ |
| Q11 人工与租金 | 员工含兼职大约几人？月人工是否含老板劳动报酬？租金物业是固定、营业额抽成，还是两者结合？ |
| Q12 平台与促销 | 外卖销售额扣除哪些费用后到手？包装、配送、平台费用、商家承担优惠分别如何计？ |
| Q13 趋势与比较 | 与此前哪个时期相比，客流或利润有何变化？是否同时有节假日、活动、竞争店或天气影响？ |
| Q14 经营约束 | 如果只改一件事，您最希望改什么？限制来自资金、场地、人手，还是总部权限？ |

顾客开场：您好，我们在做课程调研，能否占用您约1分钟，了解今天的消费体验？不记录姓名或联系方式，不方便也没关系。

| 编号 | 顾客问题 | 记录要点 |
| --- | --- | --- |
| C1 | 今天为什么选择这家？ | 先让对方自由回答，避免提示价格或口味。 |
| C2 | 第一次来还是以前来过？以前大概来过几次？ | 只描述受访者，不据此计算全店复购率。 |
| C3 | 本次实际大概花多少、几人用餐？是否用了优惠？ | 总金额÷人数得到本次人均；未结账则标预估。 |
| C4 | 最满意和最想改善的地方是什么？ | 记录具体经历；可追问是否影响下次选择。 |

每店争取2—3名已完成消费、愿意交流的顾客；样本不足写实际数量。不拦截赶时间的人，不记录无关个人信息。

遇到拒访：感谢后换备选店。只有店员可访：问其了解的客群与忙闲，不要求猜测利润。无成本信息：记录未知，后续分析盈亏平衡条件。

## 08 事后分析｜经营估算与门店对照

先统一研究月份、实际营业天数、含税口径及收入确认方式。节假日单列；工作日天数＋周末天数＋单列节假日天数不得重复。

月堂食收入＝工作日天数×日均人数×对应实付人均＋周末天数×日均人数×对应实付人均＋其他单列时段收入。若采用订单口径，整式改用订单数×每单金额。

月外卖收入＝各类营业天数×对应日均订单×对应每单金额，分项相加。使用结算额时不得重复扣已扣平台费用；促销和损耗同样避免重复。

月经营结余＝收入合计－食材及损耗－人工－租金物业－水电燃气－平台等经营费用。未含税费、折旧、老板报酬等时，注明范围，不称完整净利润。
